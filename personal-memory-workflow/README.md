# Personal Memory Workflow

规定何时召回和沉淀个人记忆，并要求与 `long-term-memory` 配合使用。

## 内容结构
1. **Recall before acting**：非简单任务、陌生项目/子系统、决策、澄清或压缩后续作前先检索。
2. **检索范围与层次**：从 `project` 开始；无有效命中才扩大到 `all-projects`；按主题逐层缩小，最多三层。
3. **记忆引用**：使用检索结果时，在首行注明记忆 ID 与日期。
4. **Persist durable outcomes**：任务结束时保存可复用决策、陷阱或流程；先查重。
5. **隐私与禁记**：不存临时状态、凭据、PII 或冗长日志。
6. **失败处理**：处理初始化、配置错误和项目范围无命中等情况。
