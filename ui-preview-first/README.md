# UI Preview First

在改动 UI 布局、层级或组件结构前先展示 ASCII 线框并取得用户一句确认。

## 内容结构
1. **改前步骤**：用一句话说明意图；绘制变更后的线框，已有界面则同时给出 BEFORE。
2. **差异清单**：最多四条说明新增、移动、移除或合并的区域。
3. **确认门槛**：请求一行确认，收到后再编辑文件。
4. **线框规范与示例**：使用边界、分隔、交互控件和滚动区域标记表达层级。
5. **跳过条件**：纯 handler 改名、不会改变布局的颜色/间距/文案调整等。

## 核心约束
此预览门槛针对视觉结构变化；创意功能/行为变更还应先遵循 `brainstorming` 设计门槛。

参见 [`SKILL.md`](SKILL.md)。
