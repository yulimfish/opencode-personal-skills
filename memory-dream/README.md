# Memory Dream

批量整理 opencode-mem：回忆近期片段、按主题聚类、沉淀长期记忆，并扫描衰减候选供用户确认。

## 内容结构
1. **触发与禁用条件**：适合集中整理，不作为每轮例行步骤。
2. **睡眠周期总览**：N1 Recall → N2 Cluster → N3 Consolidate → NREM Decay → REM Prune；仅要求清理/遗忘时走 NREM + REM 快速路径。
3. **N1–N3**：提取记忆、按主题聚类、合并至少两条的簇，并处理新旧决策冲突。
4. **契约冲突门**：比对相关规则；冲突时暂停写入并交用户选择。
5. **L2 Skill Seeds**：只提出重复成功流程的技能化建议，不自行创建或发布。
6. **NREM 衰减扫描**：R-score 公式、重要性/新鲜度/衰减率、T0–T4 分层和扫描步骤。
7. **REM 删除确认**：预览后取得明确同意；列明永不删除的记忆类别。
8. **输出格式与反模式**：报告合并、扫描、删除和冲突结果。

## 安全底线
永不自动 forget；永不建议删除 T3/T4、置顶规则或用户画像事实；保留相关簇中最新的锚点记忆。
