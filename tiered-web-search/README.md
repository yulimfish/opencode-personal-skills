# Tiered Web Search

用现有 `websearch` / `webfetch` 工具提供快速查询、多源研究和已知 URL 抓取三种检索模式。

## 内容结构
1. **范围与调用前提**：外部网络检索；本地文件和私有知识库走相应工具。
2. **严格工具边界**：只用既有 web 工具；不调用外部 API、curl、SDK 或凭据。
3. **模式选择**：Quick Search、Research Search、Fetch by URL。
4. **各模式步骤**：查询构造、来源选择、有限次数搜索/抓取及停止条件。
5. **研究质量**：优先原始来源，标注证据不足、日期缺失、页面失败或来源冲突。
6. **响应与故障规则**：使用用户语言，只引用实际获取到的 URL 和信息，不补猜缺失内容。
