# Personal Release Workflow

涵盖个人仓库/包发布中的身份隐私、分发方式、kit 注册、验证、归档与记忆记录。

## 内容结构
1. **身份与邮箱**：区分本地提交身份、登录邮箱和公开联系邮箱，防止私密邮箱进入公开元数据。
2. **误用身份后的修复**：列出作者信息核验与 amend 流程，并强调历史改写需要备份和明确授权。
3. **发布触发词**：识别发布、开源、打包或加入 kit 的请求。
4. **发布步骤**：开源仓库与许可、按产物类型分发、在 `opencode-workflow-kit` 注册、验证安装脚本与远端状态。
5. **归档与记忆**：写入带日期的工作区记录并保存发布结论。

## 隐私底线
不把登录邮箱或凭据写入公开文件；不因用户要求发布就跳过 Git 安全和验证要求。

参见 [`SKILL.md`](SKILL.md)。
