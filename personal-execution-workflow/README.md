# Personal Execution and Tool Workflow

把个人执行经济原则与工具调用纪律合并为多步骤工作的执行规范。

## 内容结构
1. **硬性工具规则**：优先专用工具、并行独立调用、宽窗口读取、先读后改、参数核对。
2. **风险与投入**：按 Level 1–3 匹配验证和审计，并区分风险与复杂度。
3. **验证成本**：检查必须能发现高概率问题、防止损失或满足验收；避免重复检查。
4. **连续执行与汇报**：正常中间步骤不停车，阶段间只发简短进度。
5. **完成门槛**：运行相关验证、复现问题，或明确说明未验证原因。
