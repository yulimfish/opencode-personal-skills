# Screenshot-to-UI

根据指定参考图高保真重建生产级界面；以忠实还原为先，不擅自“优化”参考设计。

## 内容结构
1. **与 frontend-design 的分工**：参考图锁定结构与视觉；新设计才由创意型技能主导。
2. **编码前输入**：确认参考资产、目标技术栈、页面范围、迭代预算和响应式要求。
3. **五阶段流程**：分析设计 token → 语义 HTML 结构计划 → 样式实现 → 视觉差异核对 → 按严重程度迭代。
4. **多截图/长页面**：按滚动顺序分段构建，检查相邻区段连续性并做最终全页比对。
5. **反模式**：不跳过结构草图、不臆造颜色字体、不添加参考中没有的功能、不虚称像素级一致。
6. **交付格式**：报告迭代轮数、差异、文件、token、剩余问题和素材替换。
