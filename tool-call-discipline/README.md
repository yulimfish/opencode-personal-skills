# Tool Call Discipline

通过选对工具、并行独立操作和宽窗口读取，减少多工具任务中的浪费与误操作。

## 内容结构
1. **五条硬规则**：工具优先、并行调用、宽范围读取、先读后写、参数 sanity check。
2. **工具路由表**：文件读写、搜索、变量查看和命令执行的首选方式。
3. **并行原则**：互不依赖的调用放在同一轮；按结果推进的操作才串行。
4. **读取窗口**：陌生文件先读至少 100 行；大文件先定位再按需读取。
5. **参数核对**：确认绝对路径、字段名和真实参数，不编造配置值。
6. **失败处理与反模式**：读取实际错误，针对原因最多重试一次，不盲目换工具。
