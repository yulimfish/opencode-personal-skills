# Agent Cluster (Swarm)

把一项任务拆给 2–4 个短期并行 worker，并由主代理统一综合结果。

## 内容结构
1. **启用判定**：存在独立子任务、多视角收敛需求或明确并行请求时启动；顺序任务不启动。
2. **并发与模型策略**：单波最多四个，429 时降为两个；不嵌套集群。
3. **分解模式**：任务切片、多角度评估、区域扫描。
4. **worker Prompt 模板**：定义角色、切片、排除范围、上下文、交付物和返回格式。
5. **综合规则**：全员返回后按共识、票数、置信度处理分歧；必要时委托综合。
6. **失败与成本护栏**：处理阻塞、越界输出、超时和重启；限制无效并行开销。
