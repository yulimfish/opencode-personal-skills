# Personal Swarm Workflow

限定个人并行子代理的启用场景、规模、失败处理与结果合并规则。

## 内容结构
1. **何时启用**：任务可拆为独立部分、需要多角度收敛或用户明确要求并行。
2. **何时不启用**：单文件小改、一次性查询、强顺序任务。
3. **协调与限流**：2–4 个并行 worker、遇 429 降并发、禁止嵌套集群。
4. **分解模式**：按任务切片、多角度讨论或按区域扫描。
5. **Prompt 模板**：明确 persona、任务边界、已知上下文、交付物和格式。
6. **综合与失败处理**：等待所有 worker，按 consensus > majority > confidence 合并；说明阻塞或遗漏。
7. **成本控制**：不对小任务过度并行，必要时一次性纠正分工。
