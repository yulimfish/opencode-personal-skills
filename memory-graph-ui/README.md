# Memory WebUI

介绍 opencode-mem 内置的本地记忆时间线与用户画像界面，以及它和 OpenCode 进程的生命周期关系。

## 内容结构
1. **服务生命周期**：OpenCode 启动时自动启动，退出时停止；受 `webServerEnabled` 配置控制。
2. **固定地址**：`http://127.0.0.1:4747`。
3. **自然语言请求映射**：打开、关闭、查询状态时应给出的操作或答复。
4. **反模式**：不另起服务，不在未被要求时 curl 探测。
5. **实现参考**：端口配置位置与内置功能说明。

## 边界
“关闭”实际意味着退出 OpenCode；内置 UI 是时间线/画像查看器，不是 3D 关系图。

参见 [`SKILL.md`](SKILL.md)。
