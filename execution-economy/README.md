# Execution Economy

以最小充分成本安全、完整地抵达用户要求的最终状态；仅在真实风险或实际失败出现时增加步骤。

## 内容结构
1. **最终目标优先**：区分最终交付与中间动作。
2. **风险分级**：Level 1 可逆、Level 2 中等、Level 3 高风险不可逆，各自匹配执行、验证与审计强度。
3. **验证与范围控制**：只做能发现实际问题、避免损失或满足明确验收的检查；优先窄范围操作。
4. **自动化与环境问题**：一次失败后比较更简单路径；绕开不相关环境问题。
5. **连续执行**：授权完整任务后连续完成正常步骤，只在阶段变化或重要异常时汇报。
6. **退出准则与反模式**：避免重复验证、隔离升级循环及为理论风险无限加固。
7. **与相关 skill 的职责边界**：说明何时由工具纪律、审计、澄清和集群流程接手。

## 使用要点
风险等级与任务复杂度是两条独立轴；验证以合理置信度为目标，不追求形式上的穷尽。
