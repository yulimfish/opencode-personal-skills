# Long-Term Memory

说明如何通过 opencode-mem 的 `memory` 工具跨会话检索、记录和查看长期记忆。

## 内容结构
1. **工具与自动能力**：向量后端、自动捕获、去重、用户画像及上下文压缩。
2. **操作速查**：`search`、`add`、`list`、`profile`、`forget` 示例。
3. **检索范围顺序**：先 `project`，无命中再到 `all-projects`，最后才询问用户。
4. **分层搜索**：何时一次搜索足够、何时逐层收敛，以及最多三层的限制。
5. **记忆写入规范**：触发条件、禁止记录项、日期化自包含内容格式。
6. **profile / list 边界、成本与故障处理**。
7. **Memory WebUI 交叉引用**：界面行为另见 `memory-graph-ui`。

## 重要约束
不写入密钥、PII、临时状态或重复事实；记忆命中被用于决策时，应在回复中引用记忆 ID 和日期。

参见 [`SKILL.md`](SKILL.md)。
