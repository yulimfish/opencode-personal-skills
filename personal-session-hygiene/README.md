# Personal Session Hygiene

记录上下文压缩参数约束，以及自动化浏览器会话的收尾要求。

## 内容结构
1. **上下文压缩**：遵守 `dcp.jsonc` 的比例限制与模型专属覆盖；避免退回固定绝对阈值。
2. **浏览器会话**：使用 `agent-browser` 或等价工具后必须关闭会话，不留到隔夜。
3. **故障关联**：解释 stale session 可能引发 Chrome Mojo IPC 忙循环，并指向相关排查记录。

## 使用边界
只在涉及压缩策略或自动化浏览器时加载；不要把清理浏览器扩大成无关环境治理。

参见 [`SKILL.md`](SKILL.md)。
