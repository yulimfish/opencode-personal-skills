# Personal Plan and Audit Workflow

为非平凡计划、高风险执行和独立审计提供 Plan → Build → Audit 闭环规则。

## 内容结构
1. **计划路由**：简单任务直做；非平凡计划加载 `writing-plans`；至少三步时维护 todo。
2. **Hard / ledger 边界**：识别 Hard 任务；仅跨阶段且需恢复时使用长期 ledger。
3. **独立审计触发器**：高风险、发布物、多文件/≥30 行修改、含糊验收或用户要求审查。
4. **审计执行**：用新上下文的 `goal-verify` 只读检查，限制范围和维度。
5. **Hard 任务审计门槛**：先修 BLOCKER，便宜的 MAJOR 也应修复；需要时最多三轮重新审计，最终须 PASS。
6. **阶段检查点与提交规则**：仅在明确授权后提交；不以流程文档替代用户授权。

## 交付要求
审计结果须报告审计员、结论、问题数量及证据；未审计时说明原因。
